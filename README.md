# IRON COACH — готовый сайт

Статический адаптивный сайт фитнес-тренера.

## Файлы
- `index.html` — главная страница
- `style.css` — дизайн и адаптивная верстка

## Публикация
Загрузите оба файла на любой хостинг статических сайтов или веб-хостинг.

## Что заменить перед запуском
1. Название IRON COACH и данные тренера.
2. Блок «ВАШЕ ФОТО» на фотографию тренера.
3. Демонстрационные результаты клиентов.
4. Цены.
5. Контакты и ссылки на Telegram/WhatsApp.
6. Подключить обработчик формы/CRM.

Сайт не требует базы данных и JavaScript-сервера: это обычный HTML/CSS/JS.
